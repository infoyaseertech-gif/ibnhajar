# Ibn Hajar Foundation-Zaria — Website (Phase 1: Public Site)

Flat file structure (no subfolders) to match how it's already uploaded on GitHub:
index.html, about.html, academics.html, admissions.html, staff.html, gallery.html,
contact.html, portal.html, style.css, script.js, logo.svg, README.md

## Deploy
Netlify: drag this folder into "Deploy manually" on app.netlify.com
Vercel: connect the GitHub repo, framework preset = "Other", deploy.

## Phase 2 — Database & login system (Supabase)
Create a free project at supabase.com, send the Project URL + anon public API key,
and the real login/results/fees/admissions system gets built on top of this site.
